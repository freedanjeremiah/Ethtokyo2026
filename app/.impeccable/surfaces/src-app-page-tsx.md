# Fleet dashboard (/)

Scope: the single-route ENF dashboard. Mode: Operate (presenter-driven live demo for ENS-track judges, projector, 3 m).

Audience and job: judges must grasp "one fleet, many doorways" in seconds, then watch one click change several doorways. Presenter types names and fires kill switches. Content: live chain scan (doorways, agents, verdict cells, events), single-name verifier with C1-C5 evidence, fork-only kill switches.

Constraints: category standard played straight, quality bar = ENS Manager app. Not a generic dark crypto dashboard, not text-heavy, must look finished.

## Direction contract

THESIS: One fleet, many doorways, shown as a clean ENS-app style product page: the fleet map is the page, and every other panel explains what the map just did. Refuses the dark neon stats-cards-graph dashboard.

OWN-WORLD: ENS Manager family. Light cool-grey canvas, white rounded surfaces (one radius scale: 16px panels, 10px controls, full pill for tags), ENS blue as the only accent for action and selection, verdict colours used only for verdict state. Satoshi for all type, tabular numerals for data, mono only for addresses and hashes. Phosphor icons, one stroke weight.

STORY: see the fleet mounted under four names with one counterfeit flagged; press one kill switch; watch the affected doorways go dark on the map and grid next block; inspect any name for the evidence.

FIRST VIEWPORT: top bar with ENF wordmark, ENS name search field centred and wide, block pill right. Below, one large map panel spanning two thirds, with a short plain sentence summary above it (no KPI tile row); right third holds the kill switch panel with grouped actions. Agent x doorway grid and inspector below the fold line on a laptop, visible on 1080p.
